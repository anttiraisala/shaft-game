# Rules

Single source of truth for the game rules. The Godot version and the future
Commodore 64 version must follow this file. The tunable numbers for Godot live
in `godot/scripts/rules.gd`; keep both in sync.

Status: describes prototype v0.1 (the current basic game).

## Round

- A round has 333 floors, numbered from 1 at the top. It starts on floor 1.
  (Random start floors are planned, see the project plan.)
- The platform arrives from above, stops on a floor, and leaves downwards.
- The player must be standing on the platform when it leaves. If not, the
  round ends ("You missed the platform"). Falling into the shaft also ends it.
- A round is won when the platform leaves floor 333 with the player aboard.

## Platform and lights

- The platform stays stopped for a time that shrinks linearly with depth:
  14 seconds on floor 1 down to 5 seconds on floor 333.
- Green light: the platform is stopped and there is time to act.
- Red light: the last 2 seconds before leaving, and while it is leaving.
- No light (dark): the platform is still arriving.

## Food and hunger

- Every floor has one ledge with one piece of food.
- Hunger starts at 5 (maximum 5). Each floor passed costs 1 hunger.
- Collecting a piece of food restores 2 hunger (not above the maximum).
- At 0 hunger the round ends ("starved").

## Floor layout generator

The layout of a floor is derived only from its floor number, so it needs no
storage and is identical in every version.

Random numbers come from a 16-bit xorshift generator with shifts 7, 9 and 8
(all operations masked to 16 bits):

```
x = x XOR (x << 7)    (mask to 16 bits)
x = x XOR (x >> 9)
x = x XOR (x << 8)    (mask to 16 bits)
```

Seed for a floor: `(floor * 40503 + 1) AND 0xFFFF`, or 1 if that is 0.

Per floor, take three successive states `s1`, `s2`, `s3` starting from the seed:

| Value | Rule |
| --- | --- |
| Side of the ledge | left room if `s1` is even, otherwise right room |
| Ledge center x (pixels) | `80 + s2 mod 361` for the left room, `840 + s2 mod 361` for the right room |
| Ledge height above the floor (pixels) | `80 + s3 mod 31` |

Pixel values assume the 1280 x 720 Godot layout. The C64 version will scale
them to its own screen.

Test vectors for all 333 floors are in `shared/test-vectors/floor_layout.csv`.
They are generated by `tools/generate_test_vectors.py` (the reference
implementation) and checked against the Godot code by
`godot/tests/check_vectors.gd`.
